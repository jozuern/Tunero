# Secure-Boot-Zertifikate von 2023

## Zusammenfassung
::: status Info
Die Secure-Boot-Zertifikate von 2023 sind nicht vollständig installiert. Der Start funktioniert weiter, künftige Sicherheitsupdates für den Start brauchen sie aber.
:::
::: status Ok
Die Secure-Boot-Zertifikate von 2023 sind installiert.
:::
::: status Unknown,Problem,Unsupported
Prüft, ob die Firmware Microsofts Secure-Boot-Zertifikate von 2023 hat, die die von 2011 ablösen.
:::

## Warum das wichtig ist
Secure Boot startet nur Startsoftware, die mit Zertifikaten aus der Firmware signiert ist. Microsofts Zertifikate von 2011 sind im Juni 2026 (KEK CA 2011, UEFI CA 2011) und im Oktober 2026 (Windows Production PCA 2011) abgelaufen [1]. PCs brauchen die neuen Zertifikate von 2023 in den Listen KEK und db, um weiter neue Schutzmaßnahmen für die frühe Startphase zu bekommen, etwa Updates für den Windows-Start-Manager und die Secure-Boot-Sperrlisten. Laut Microsoft startet und läuft ein PC ohne sie normal weiter und bekommt auch die üblichen Windows-Updates [1]. Anti-Cheats, die Secure Boot verlangen, funktionieren weiter, der PC bekommt aber diese neuen Startschutzmaßnahmen nicht. Auf die Spieleleistung hat das keinen Einfluss.

## Wie wir es erkennen
Wir lesen die Firmware-Variablen KEK und db (nur lesend, braucht Administratorrechte) und suchen darin nach den Namen der Zertifikate von 2023. Außerdem zeigen wir den Status, den Windows für das Zertifikatsupdate meldet (NotStarted, InProgress oder Updated) [2].
::: variant notElevated
Starte die App als Administrator, um die Firmware-Variablen zu lesen.
:::

## So behebst du es
1. Installiere alle Windows-Updates. Microsoft liefert die neuen Zertifikate an die meisten Geräte automatisch aus [1].
2. Bleibt der Status nach Updates und Neustarts gleich, installiere das neueste BIOS für dein {{board}}. Manche Mainboards brauchen ein Firmware-Update, bevor Windows die neuen Zertifikate schreiben kann. Nutzt dein Systemlaufwerk BitLocker, setze es vor einem BIOS-Update aus, das nicht über Windows Update kommt, sonst fragt Windows beim nächsten Start womöglich nach dem Wiederherstellungsschlüssel [3].
3. Ändere die Secure-Boot-Schlüssel nicht von Hand, außer der Mainboard-Hersteller sagt es dir.

## So prüfst du die Behebung
Starte den Scan erneut als Administrator. KEK CA 2023 und Windows UEFI CA 2023 sollten „Vorhanden“ zeigen.
