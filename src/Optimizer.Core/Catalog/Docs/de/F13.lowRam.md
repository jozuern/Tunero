# Wenig RAM (8 GB oder weniger)

## Zusammenfassung
::: status Problem
Der PC hat 8 GB RAM oder weniger. Viele aktuelle Spiele brauchen zusammen mit Windows, Browser und Chat mehr. Das Auslagern auf das Laufwerk verursacht Ruckler.
:::
::: status Ok,Unknown,Info,Unsupported
Prüft, ob der PC mehr als 8 GB RAM hat.
:::

## Warum das wichtig ist
Brauchen Spiel, Windows und Hintergrund-Apps mehr Speicher, als eingebaut ist, verschiebt Windows Daten in die Auslagerungsdatei auf dem Laufwerk und lädt sie bei Bedarf zurück. Selbst auf einer schnellen SSD dauert das viel länger als ein Speicherzugriff. Man merkt es an Rucklern und schlechten 1-%-Lows, weniger an niedrigeren Durchschnitts-FPS. Manche aktuellen Spiele nennen 16 GB sogar als Mindestanforderung, zum Beispiel Starfield [1]. Keine Software-Einstellung ersetzt fehlenden RAM.

## Wie wir es erkennen
Wir lesen den eingebauten RAM aus Windows (WMI), sowohl die Gesamtmenge, die Windows meldet, als auch die Summe der eingebauten Module. 8 GB oder weniger gelten als wenig. Die Grenze haben wir selbst anhand aktueller Spielanforderungen gewählt.

## So behebst du es
1. Rüste auf 16 GB auf, für aktuelle Spiele mit Streaming oder vielen Hintergrund-Apps auf 32 GB.
2. Kaufe zwei gleiche Module (ein Kit), damit der Speicher im Dual-Channel läuft (siehe den Dual-Channel-Check).
3. Prüfe im Handbuch des Mainboards oder in den Laptop-Daten den passenden Typ (DDR4 oder DDR5), die Geschwindigkeit und ob der Speicher verlötet ist.
4. Bis dahin: Schließe beim Spielen Browser und andere große Apps.

## So prüfst du die Behebung
Starte den Scan nach dem Aufrüsten erneut. Beim eingebauten RAM sollte die neue Größe stehen.
