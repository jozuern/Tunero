# Ryzen X3D mit zwei Chiplets: Energiesparplan

## Zusammenfassung
::: status Problem
Dein Ryzen X3D hat 3D V-Cache auf einem von zwei Chiplets. Der Plan ist nicht „Ausbalanciert“ oder Core Parking ist aus, Spiele landen womöglich auf dem Chiplet ohne Zusatz-Cache.
:::
::: status Ok
Dein Ryzen X3D hat 3D V-Cache auf einem von zwei Chiplets. „Ausbalanciert“ ist aktiv, damit bleibt Core Parking für AMDs Treiber verfügbar.
:::
::: status Unknown,Info,Unsupported
Dein Ryzen X3D hat 3D V-Cache auf einem von zwei Chiplets. Den aktiven Energiesparplan konnten wir nicht lesen.
:::

## Warum das wichtig ist
Bei diesen Prozessoren hat nur ein Chiplet (CCD) den großen gestapelten L3-Cache, der X3D-Chips in Spielen schnell macht. Der AMD-Chipsatztreiber installiert den „3D V-Cache Performance Optimizer“. Er nutzt die Spielerkennung der Xbox Game Bar als Signal, um die Kerne des anderen Chiplets zu parken, damit das Spiel auf dem Cache-Chiplet läuft [1]. Das funktioniert nur mit Core Parking. Windows schaltet Core Parking ganz ab, wenn der Mindestanteil nicht geparkter Kerne auf 100 % steht [2], und genau das tun manche Tweak-Tools und eigene Pläne. Notebookcheck hat nach AMDs Empfehlung mit dem Plan „Ausbalanciert“ getestet [1]; ein AMD-Dokument, das diese Voraussetzung direkt nennt, haben wir nicht gefunden. Ohne Parking können sich Spiele auf beide Chiplets verteilen, wie stark das die Framerate beeinflusst, hängt vom Spiel ab.
::: variant parkingOff
Hier ist zwar „Ausbalanciert“ aktiv, der Mindestanteil nicht geparkter Kerne steht aber auf 100 %. Core Parking ist damit aus.
:::

## Wie wir es erkennen
Wir lesen Namen und Cache-Aufbau des Prozessors aus Windows: Ein X3D-Prozessor mit zwei L3-Cache-Bereichen deutlich unterschiedlicher Größe (der größere mindestens doppelt so groß) hat ein Chiplet mit V-Cache. Die Modellliste im Katalog bestätigt bekannte Modelle. Notebook-Chips mit zwei Kerngruppen (Ryzen AI 300) haben ebenfalls unterschiedlich große L3-Bereiche, aber keinen V-Cache, und zählen daher nicht. Dann lesen wir den Typ des aktiven Energiesparplans und ob sein Mindestanteil nicht geparkter Kerne 100 % beträgt.

## So behebst du es
1. Wähle den Plan **Ausbalanciert** unter **Systemsteuerung > Hardware und Sound > Energieoptionen**.
2. Installiere den aktuellen AMD-Chipsatztreiber von amd.com (er enthält den V-Cache-Optimizer [1]).
3. Lass die Xbox Game Bar installiert und aktuell. Entferne sie nicht mit Debloat-Tools.
4. Hat ein Tweak-Tool Core Parking abgeschaltet, mach die Änderung im Tool rückgängig oder setze den Plan „Ausbalanciert“ auf seine Standardwerte zurück (Systemsteuerung > Energieoptionen > Energiesparplaneinstellungen ändern > Standardeinstellungen für diesen Energiesparplan wiederherstellen).

## So prüfst du die Behebung
Starte den Scan erneut. Während eines Spiels sollte der Task-Manager die Last vor allem auf den Kernen eines Chiplets zeigen.
