# Altlasten anderer Tweak-Tools

## Zusammenfassung
::: status Problem
Die Startoption useplatformclock steht auf Yes. Ältere Tweak-Anleitungen setzen sie. Jede Zeitstempel-Abfrage nutzt dann einen langsameren Timer.
:::
::: status Ok,Unknown,Info,Unsupported
Sucht nach Startoptionen anderer Tweak-Tools, die Zeitstempel-Abfragen auf aktuellen PCs verlangsamen.
:::

## Warum das wichtig ist
Programme und Spiele fragen Windows nach genauen Zeitstempeln; wie oft, ist von Programm zu Programm verschieden. Normalerweise antwortet Windows aus dem Zeitstempelzähler des Prozessors (TSC), was einige Dutzend bis einige Hundert CPU-Takte dauert, und weicht nur dort auf einen Plattform-Timer (HPET oder ACPI-PM-Timer) aus, wo der TSC nicht geeignet ist [2]. Die Startoption useplatformclock erzwingt den Plattform-Timer, für den Microsoft etwa 0,8 bis 1,0 µs plus einen Systemaufruf pro Abfrage angibt [2]. Microsoft dokumentiert die Option nur für die Fehlersuche [1].

## Wie wir es erkennen
Wir lesen den Starteintrag {current} mit bcdedit. Das braucht Administratorrechte, ohne sie ist das Ergebnis unbekannt. Die Option zählt als Altlast, wenn sie auf Yes steht, denn dann erzwingt sie den Plattform-Zeitgeber. Steht sie auf No, wiederholt sie nur, was Windows ohnehin tut, und wird nicht gemeldet.

## So behebst du es
Unter Tweaks > Altlasten gibt es „Erzwungene Plattformuhr entfernen“. Das ist eine Experten-Änderung, weil sie die Startkonfiguration betrifft. Halte BitLocker vorher an, wenn dein Systemlaufwerk damit verschlüsselt ist.

## So prüfst du die Behebung
Starte den PC neu und danach den Scan erneut. Die Liste sollte leer sein.
