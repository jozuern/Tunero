# Globale NVIDIA-Einstellungen bremsen jedes Spiel

## Zusammenfassung
::: status Problem
Eine globale NVIDIA-Einstellung bremst jedes Spiel: ein niedriges FPS-Limit oder der auf Minimum gestellte Energiemodus. Ein Klick behebt das.
:::
::: status Info
::: if vsyncForced
V-Sync ist global ohne G-SYNC erzwungen. Das verhindert Tearing, verzögert aber jedes Spiel.
:::
::: if gsyncNoCap
G-SYNC und erzwungenes V-Sync ohne FPS-Limit: Spiele über {{refresh}} Hz bekommen V-Sync-Verzögerung.
:::
:::
::: status Ok
Das globale NVIDIA-Profil enthält keine Einstellung, die Spiele begrenzt.
:::
::: status Unknown,Unsupported
Prüft das globale NVIDIA-Profil auf Einstellungen, die alle Spiele begrenzen.
:::

## Warum das wichtig ist
Einstellungen unter **NVIDIA-Systemsteuerung > 3D-Einstellungen verwalten > Globale Einstellungen** gelten für jedes Spiel ohne eigenen Wert. Tools und Anleitungen hinterlassen dort manchmal Werte, die überall Leistung kosten.
::: if lowCap
Ein globales FPS-Limit von {{cap}} FPS an einem {{refresh}}-Hz-Bildschirm begrenzt jedes Spiel weit unter das, was der Bildschirm zeigen kann. Ein Limit wenige FPS unter der Refresh-Rate ist in Ordnung und die übliche G-SYNC-Einstellung, daher melden wir nur deutlich niedrigere Limits.
:::
::: if powerMin
Der Energieverwaltungsmodus „Minimale Leistung bevorzugen“ hält die Grafikkarte auf niedrigen Takten. Meist setzen ihn Fremdtools, die Treiberprofile bearbeiten.
:::
::: if vsyncForced
Erzwungenes V-Sync wartet vor jedem neuen Bild auf den Bildschirm. Ohne G-SYNC verhindert das Tearing, kostet aber bis zu einen Bildwechsel Verzögerung. Mit G-SYNC ist erzwungenes V-Sync zusammen mit einem FPS-Limit mindestens 3 FPS unter der Refresh-Rate die Einstellung, die die Latenztests von Blur Busters (eine unabhängige Testseite) empfehlen [1].
:::
::: if gsyncNoCap
G-SYNC ist an und V-Sync erzwungen, das ist die empfohlene Kombination, aber es gibt kein FPS-Limit. Läuft ein Spiel schneller als {{refresh}} Hz, kann G-SYNC nicht mehr folgen, und V-Sync übernimmt. Blur Busters hat mit einer Hochgeschwindigkeitskamera gemessen, dass doppelt gepuffertes V-Sync an dieser Stelle 2 bis 6 Bilder Verzögerung bringt [3]. Ein Limit 2 FPS unter der Refresh-Rate reichte bei jeder getesteten Refresh-Rate, um das zu vermeiden; 3 FPS darunter ist die sichere Wahl, ein niedrigeres Limit verschenkt nur Bilder [4]. Spiele mit NVIDIA Reflex begrenzen sich mit G-SYNC und V-Sync selbst [1], und ein Limiter im Spiel verzögert weniger als ein Treiberlimit; es geht also um Spiele ohne beides. Die Tests stammen von 2017 mit einem Monitor mit G-SYNC-Modul; am Prinzip hat sich nichts geändert.
:::

## Wie wir es erkennen
Wir lesen das globale Profil (das Basisprofil der Treibereinstellungen) über NVIDIAs dokumentierte Schnittstelle für Treibereinstellungen (NVAPI DRS) [2] und den G-SYNC-Status jedes Bildschirms. Es zählen nur Werte, die im Profil gespeichert sind; die Treiberstandards sind in Ordnung.

## So behebst du es
::: status Problem
::: ifnot capInReset
1. Nutze die Ein-Klick-Behebung: Sie entfernt den eigenen Wert des globalen Profils für die oben genannten Einstellungen, damit der Treiberstandard gilt. Rückgängig machen stellt deine Werte wieder her.
2. Wenn du ein FPS-Limit für G-SYNC willst, setze es wenige FPS unter die Refresh-Rate.
:::
::: if capInReset
1. Nutze die Ein-Klick-Behebung: Hier sind G-SYNC und V-Sync an, darum setzt sie die globale **Max. Bildrate** auf {{capTarget}} FPS, 3 FPS unter der Refresh-Rate, statt das Limit zu entfernen [4]. Jede andere oben genannte Einstellung geht auf den Treiberstandard zurück. Rückgängig machen stellt deine Werte wieder her.
2. Die Behebung ist als „Noch nicht auf einem echten PC getestet“ markiert: Prüfe in der NVIDIA App > Grafik > Globale Einstellungen, dass Max. Bildrate {{capTarget}} FPS zeigt.
:::
:::
::: status Info
::: if vsyncForced
1. Wenn dich Tearing nicht stört, stelle **Vertikale Synchronisierung** in der NVIDIA App > Grafik > Globale Einstellungen (bei älteren Treibern: NVIDIA-Systemsteuerung > 3D-Einstellungen verwalten) auf **Einstellung der 3D-Anwendung verwenden**.
2. Unterstützt der Monitor G-SYNC oder G-SYNC Compatible, schalte stattdessen das ein (siehe den Check zur variablen Refresh-Rate).
:::
::: if gsyncNoCap
1. Nutze die Ein-Klick-Behebung: Sie setzt die globale **Max. Bildrate** auf {{capTarget}} FPS. Rückgängig machen entfernt sie wieder. Die Behebung ist als „Noch nicht auf einem echten PC getestet“ markiert: Prüfe in der NVIDIA App > Grafik > Globale Einstellungen, dass Max. Bildrate {{capTarget}} FPS zeigt.
2. In Spielen mit eigenem FPS-Limiter oder mit NVIDIA Reflex ist das die bessere Wahl; das globale Limit schadet dann nicht.
3. Bei mehreren G-SYNC-Monitoren mit unterschiedlicher Refresh-Rate richtet sich das globale Limit nach dem schnellsten. Setze für den langsameren ein niedrigeres Limit pro Spiel.
:::
:::
::: status Ok,Unknown,Unsupported
Nichts zu tun.
:::

## So prüfst du die Behebung
Starte den Scan erneut. Die Werte oben sollten die Treiberstandards zeigen.
