# Power saver plan on a desktop PC

## Summary
::: status Problem
This desktop PC uses the Power saver plan. It lowers processor clocks and responsiveness to save energy, which costs performance in games.
:::
::: status Ok,Unknown,Info,Unsupported
Checks that a desktop PC does not run the Power saver plan.
:::

## Why it matters
The Power saver plan delivers reduced performance to save power [2]: it limits how high and how quickly the processor raises its clock. On a laptop on battery that is a reasonable trade-off. On a desktop it only costs speed, and games limited by the processor can get lower frame rates and worse 1 % lows. How much depends on the processor and the game; we have no measured figure for it. Balanced is the Windows default and works well on most desktops; High performance or Ultimate Performance keep clocks higher at idle.

## How we detected it
We read the active power plan and its base type ("personality"), so a renamed copy of the Power saver plan is still recognized. The check runs only on desktop PCs.

## How to fix
1. Open **Control Panel > Hardware and Sound > Power Options**. The Settings app does not list power plans.
2. Select **Balanced**. If **High performance** is listed (sometimes under **Show additional plans**), you can choose it instead. Once Balanced is selected, Windows may not offer High performance in its user interface again [1].
3. On an AMD Ryzen processor with 3D V-Cache on only one of two chiplets (for example 7950X3D or 9950X3D), choose **Balanced**; see the check "Ryzen X3D with two chiplets: power plan".

## How to check the fix
Run the scan again. The plan type should no longer be "Power saver".
