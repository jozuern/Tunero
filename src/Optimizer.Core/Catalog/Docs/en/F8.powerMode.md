# Power mode set to best power efficiency

## Summary
::: status Problem
Windows power mode is set to "Best power efficiency" while the PC is plugged in. That can lower processor clocks in games; on some desktops it changes little.
:::
::: status Ok,Unknown,Info,Unsupported
Checks the Windows power mode while the PC is plugged in.
:::

## Why it matters
With the Balanced plan, Windows has a power mode slider: best power efficiency, balanced and best performance [1]. Each step changes how fast the processor raises its clock and how much power it may use. "Best power efficiency" saves energy on battery, but while plugged in it can cost frame rate, especially in games that depend on the processor. How much depends on the PC: Windows has its own values for the modes only on PCs with a battery; on a desktop they come from the PC maker, if at all, so the mode may change little or nothing there [1]. That is why the app rates it higher on laptops. No published measurement gives a number.

If you set "Best power efficiency" on purpose, for example with this app's **Quiet and cool** profile, you can ignore this.

## How we detected it
We read the effective power mode overlay through the Windows power API and check that the PC runs on mains power and uses the Balanced plan (other plans hide the slider). The API is not documented by Microsoft, so the check only runs when Windows provides it. If Windows cannot tell whether the PC is plugged in, the check is skipped.

## How to fix
1. Use the one-click fix: it sets the power mode to **Best performance** for mains power. Undo restores your previous mode.
2. Or open **Settings > System > Power** (laptops: **Power & battery**) and choose **Power mode > Best performance**.

## How to check the fix
Run the scan again. The power mode should show "Best performance".
