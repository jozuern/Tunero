# Memory integrity is on

## Summary
::: status Info
Memory integrity (core isolation) is on. It protects the Windows kernel and costs a few percent in games limited by the processor.
:::
::: status Ok
Memory integrity is off, so it costs no frame rate here.
:::
::: status Unknown,Unsupported
Checks whether memory integrity (core isolation) is running.
:::

## Why it matters
Memory integrity runs the kernel's code integrity checks in an environment that the Windows hypervisor isolates (virtualization-based security, VBS) [1]. Beginning in October 2026, Windows quality updates turn it on for more eligible PCs, together with VBS where needed; PCs where it was turned off keep that setting [2]. So a game can run slower after an update without any other change.
ComputerBase measured it on a Ryzen 7 5800X at 720p, where the processor limits, in 14 games: with memory integrity on, 6 % lower average frame rates and 8 % lower 1 % lows, and in Diablo II Resurrected 12 % and 26 % [3]. When the graphics card limits, the difference is smaller [3].
::: variant noMbec
This processor has no MBEC (Intel) or GMET (AMD), so Windows emulates these features, which Microsoft says costs more [1]. ComputerBase measured close to 10 % fewer frames on a Ryzen 7 1800X, which has neither [4].
:::
It is a security feature: it lets only trusted kernel code and drivers run [1], and some anti-cheats can ask for it: FACEIT for some players, and Riot Vanguard depending on the PC [5][6].

## How we detected it
We read Win32_DeviceGuard: whether VBS runs, whether memory integrity is among the running security services, and whether the processor offers MBEC or GMET [1].

## How to fix
::: status Info
1. Keep it on if you play games with FACEIT or Riot Vanguard, or if a few percent matter less to you than kernel protection.
2. To trade it for frame rate: **Windows Security > Device security > Core isolation details > Memory integrity**, turn it off and restart [1]. Or turn on Expert mode and use the tweak "Virtualization-based security and memory integrity off", which the app backs up and can undo.
:::
::: status Ok,Unknown,Unsupported
No action needed.
:::

## How to check the fix
Restart, then run the scan again.
