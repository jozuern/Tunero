# Leftovers from other tweak tools

## Summary
::: status Problem
The boot option useplatformclock is set to Yes. Older tweak guides set it; it makes every time stamp query use a slower timer.
:::
::: status Ok,Unknown,Info,Unsupported
Checks for boot options left by other tweak tools that slow down time stamp queries on current PCs.
:::

## Why it matters
Programs and games ask Windows for precise time stamps; how often differs from program to program. Windows normally answers from the processor's own time stamp counter (TSC), which takes tens to hundreds of processor cycles, and falls back to a platform timer (HPET or ACPI PM timer) only where the TSC is not suitable [2]. The boot option useplatformclock forces the platform timer, which Microsoft lists at about 0.8 to 1.0 µs plus a system call per query [2]. Microsoft documents the option for debugging only [1].

## How we detected it
We read the boot entry {current} with bcdedit. This needs administrator rights; without them the result is unknown. The option counts as a leftover when it is set to Yes, which forces the platform timer. Set to No, it only repeats what Windows does anyway, so it is not reported.

## How to fix
Tweaks > Leftovers has "Remove forced platform clock". It is an Expert change because it touches the boot configuration; suspend BitLocker first if your system drive uses it.

## How to check the fix
Restart the PC and run the scan again. The list should be empty.
