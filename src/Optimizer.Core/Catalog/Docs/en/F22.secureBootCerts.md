# Secure Boot certificates from 2023

## Summary
::: status Info
The 2023 Secure Boot certificates are not fully installed. Booting still works, but future boot security updates need them.
:::
::: status Ok
The 2023 Secure Boot certificates are installed.
:::
::: status Unknown,Problem,Unsupported
Checks whether the firmware has Microsoft's 2023 Secure Boot certificates, which replace the 2011 ones.
:::

## Why it matters
Secure Boot only starts boot software signed by certificates stored in the firmware. Microsoft's certificates from 2011 expired in June 2026 (KEK CA 2011, UEFI CA 2011) and October 2026 (Windows Production PCA 2011) [1]. PCs need the new 2023 certificates in the KEK and db lists to keep receiving new protections for the early boot phase, such as updates for the Windows boot manager and the Secure Boot block lists. Microsoft states that a PC without them keeps starting and operating normally and still gets the standard Windows updates [1], and anti-cheats that require Secure Boot keep working, but it does not get these new boot protections. This has no effect on game performance.

## How we detected it
We read the firmware's KEK and db variables (read-only, needs administrator rights) and search them for the names of the 2023 certificates. We also show the status Windows reports for the certificate update (NotStarted, InProgress or Updated) [2].
::: variant notElevated
Start the app as administrator to read the firmware variables.
:::

## How to fix
1. Install all Windows updates. Microsoft delivers the new certificates to most devices automatically [1].
2. If the status stays the same after updates and restarts, install the latest BIOS for your {{board}}. Some boards need a firmware update before Windows can write the new certificates. If your system drive uses BitLocker, suspend it before a BIOS update that does not come through Windows Update, or Windows may ask for the recovery key at the next start [3].
3. Do not change Secure Boot keys manually unless the board manufacturer tells you to.

## How to check the fix
Run the scan again as administrator. KEK CA 2023 and Windows UEFI CA 2023 should show "Present".
