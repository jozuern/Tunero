# NVIDIA global settings limit every game

## Summary
::: status Problem
A global NVIDIA setting slows down every game: a low frame rate limit or the power mode forced to minimum. One click fixes it.
:::
::: status Info
::: if vsyncForced
V-Sync is forced on globally without G-SYNC. That prevents tearing but adds delay in every game.
:::
::: if gsyncNoCap
G-SYNC and forced V-Sync but no fitting frame limit: games above {{gsyncRefresh}} Hz get V-Sync delay.
:::
:::
::: status Ok
The NVIDIA global profile has no setting that limits games.
:::
::: status Unknown,Unsupported
Checks the NVIDIA global profile for settings that limit all games.
:::

## Why it matters
Settings in **NVIDIA Control Panel > Manage 3D settings > Global Settings** apply to every game that has no own value. Tools and guides sometimes leave values there that cost performance everywhere.
::: if lowCap
A global frame rate limit of {{cap}} FPS on a {{refresh}} Hz display caps every game far below what the screen can show. A limit a few FPS below the refresh rate is fine and is the usual G-SYNC setup, so we only report limits clearly below it.
:::
::: if powerMin
The power management mode "prefer minimum power" keeps the graphics card at low clocks. It is usually set by third-party tools that edit driver profiles.
:::
::: if vsyncForced
V-Sync forced on waits for the display before every new frame. Without G-SYNC this avoids tearing but adds up to one refresh interval of delay. With G-SYNC on, forced V-Sync plus a frame limit at least 3 FPS below the refresh rate is the setup that the input lag tests of Blur Busters (a third-party test site) recommend [1].
:::
::: if gsyncNoCap
G-SYNC is on and V-Sync is forced on, which is the recommended pair, but there is no frame limit below the G-SYNC display's {{gsyncRefresh}} Hz. When a game runs faster than that, G-SYNC can no longer follow it and V-Sync takes over. Blur Busters measured with a high-speed camera that double-buffered V-Sync at that point adds 2 to 6 frames of delay [3]. A limit 2 FPS below the refresh rate was enough to stay out of it at every refresh rate they tested; 3 FPS below is the safe choice, and a lower limit only gives away frames [4]. Games with NVIDIA Reflex cap themselves with G-SYNC and V-Sync on [1], and an in-game limiter works with less delay than a driver limit, so this matters for games without either. These tests are from 2017 with a G-SYNC module monitor; the mechanism has not changed since.
:::

## How we detected it
We read the global profile (the base profile of the driver settings) through NVIDIA's documented driver settings API (NVAPI DRS) [2] and the G-SYNC state of each display. Only values stored in the profile count; the driver defaults are fine.

## How to fix
::: status Problem
::: ifnot capInReset
1. Use the one-click fix: it removes the global profile's own value for the settings listed above, so the driver default applies. Undo puts your values back.
2. If you want a frame limit for G-SYNC, set it a few FPS below the refresh rate.
:::
::: if capInReset
1. Use the one-click fix: G-SYNC and V-Sync are on here, so it sets the global **Max Frame Rate** to {{capTarget}} FPS, 3 FPS below the refresh rate, instead of removing the limit [4]. Any other setting listed above goes back to the driver default. Undo puts your values back.
2. The fix is marked "Not yet tested on a real PC": check in the NVIDIA App > Graphics > Global settings that Max Frame Rate shows {{capTarget}} FPS.
:::
:::
::: status Info
::: if vsyncForced
1. If tearing does not bother you, set **Vertical sync** to **Use the 3D application setting** in the NVIDIA App > Graphics > Global settings (in older drivers: NVIDIA Control Panel > Manage 3D settings).
2. If the monitor supports G-SYNC or G-SYNC Compatible, turn that on instead (see the variable refresh check).
:::
::: if gsyncNoCap
1. Use the one-click fix: it sets the global **Max Frame Rate** to {{capTarget}} FPS. Undo removes it again. The fix is marked "Not yet tested on a real PC": check in the NVIDIA App > Graphics > Global settings that Max Frame Rate shows {{capTarget}} FPS.
2. In games with their own frame limiter or with NVIDIA Reflex, those are the better choice; the global limit then does no harm.
3. With several G-SYNC monitors at different refresh rates, the global limit follows the fastest one. Set a lower limit per game for the slower monitor. The limit also applies to a monitor without G-SYNC on the same card; if that one is faster, set a higher limit per game there.
:::
:::
::: status Ok,Unknown,Unsupported
No action needed.
:::

## How to check the fix
Run the scan again. The values above should show the driver defaults.
